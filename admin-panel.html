Setup — One Time
  1. Open script.google.com → New Project
  2. Click Copy Script below, paste it in, replacing all existing code
  3. On line 12 of the script, paste your Google Sheet ID
  4. Click Deploy → New deployment → Web App
  5. Set Execute as: Me and Access: Anyone
  6. Authorize, copy the Web App URL, paste above
  7. Paste the same URL into customer-site.html line 3
